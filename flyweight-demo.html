Padrão de projeto Flyweight

Editor de texto, com e sem Flyweight

Digite um texto, aperte Enter e veja quantos objetos de estilo cada versão precisa criar para montar o documento inteiro.

O texto digitado se repete até completar o tamanho escolhido. Coloque *palavras entre asteriscos* para deixá-las em negrito.

Cada estilo criado simula o carregamento de uma fonte (1 KB de dados e um cálculo), por isso a versão sem Flyweight demora. O tempo é medido de verdade no seu navegador. A memória é uma estimativa: estilos × 1,1 KB + caracteres × 64 bytes.
